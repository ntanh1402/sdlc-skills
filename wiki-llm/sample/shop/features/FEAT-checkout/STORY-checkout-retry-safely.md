# Retry checkout safely

As a **shopper**, I want to retry a checkout that timed out, so that I can
finish my order without paying twice.

# Acceptance criteria

1. **Given** a checkout whose response timed out after payment, **when** the
   shopper submits it again with the same client token, **then** they see the
   same order number and the card is charged once.
   ([REQ-checkout-pay-before-confirm](overview.md#req-checkout-pay-before-confirm))

# Requirements

* [REQ-checkout-pay-before-confirm](overview.md#req-checkout-pay-before-confirm)

# Notes

The client token is generated by the web frontend when checkout starts.
