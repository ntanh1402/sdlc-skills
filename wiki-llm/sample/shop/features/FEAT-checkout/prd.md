# Checkout PRD

Customers can turn an active cart into one confirmed order. Checkout validates
the cart, authorizes payment, persists the order, and returns confirmation.

Repeated submission with the same client token must not create another order or
charge. Payment failure leaves no confirmed order and emits no order event.
